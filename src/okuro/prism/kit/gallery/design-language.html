5 · Accent scarcity

Accent = ONE highlight span per title + interactive/active states only. Never body text. One contrast per deck.

Correct: a single accent span carries the emphasis; the rest is the neutral fg ladder.

Local inference, zero cloud spend

6 · Measure caps

Reading width is bounded so lines never sprawl: title ≤22ch · lede ≤70ch · prose ≤72ch · bullet-body ≤76ch. Enforced by the harness per element font.

This paragraph is clamped to a 72-character measure. Past ~75 characters a line loses the reader on the return sweep; the cap keeps every body block inside the comfortable band regardless of column width.

7 · Mono = machine-data

The mono family is a semantic signal for machine data — ids, paths, values, timestamps, params, tags — never body prose.

Value 2.8k tok, path /inbox/list, id flow_7f3a — mono. The sentence around them stays in the body family.

8 · A11y floors

All text ≥ WCAG AA on its composited background (accent + semantic text via -text companions). --fg-tertiary/--fg-muted only at ≥14px or decorative. Touch targets ≥44px; reduced-motion honoured.

Every specimen in the gallery is scanned for AA (incl. accent + semantic-text-on-tint), type floors, whitespace and pixel-visibility. A raw accent as text on its own surface is a hard failure; the kit uses the -text role instead.
