07 Fork in the road

Ship narrow or ship whole

Path A · defer

One provider, one model

Fast to demo, but locks the roadmap to a single vendor's pricing and cadence.

Risk: lock-in, brittle
Path B · recommend

Provider-agnostic core

Route by capability, not name. Swap any model as data, never as a rewrite.

Payoff: durable, no lock-in
Recommendation

Take Path B — the abstraction cost is paid once; the flexibility compounds forever.
